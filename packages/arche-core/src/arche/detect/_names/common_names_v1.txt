# common_names_v1.txt -- extra name tokens for arche.detect.names (PII-1-NAME, basic backend)
#
# Format: one normalised token per line (diacritics stripped, lower case);
# "[section] N" lines open a section; "#" lines are comments. A token is listed
# once, in the first section that holds it.
#
# Sources and licences (all permit redistribution in this Apache-2.0 package):
#
# [us_census_2010_surnames_top3000]
#   US Census Bureau, "Frequently Occurring Surnames from the 2010 Census",
#   https://www2.census.gov/topics/genealogy/2010surnames/names.zip
#   (Names_2010Census.csv, fetched 2026-11-20). The 3,000 most frequent
#   surnames (cumulative ~54% of the population). A US federal government
#   work: public domain, 17 U.S.C. 105. Covers common English, UK, US and
#   Hispanic surnames.
#
# [wikidata_name_pairs_africa]
#   Every capitalised given- and family-name token (>= 3 letters) of
#   datasets/data/wikidata_name_pairs.jsonl in this repository: 8,156 real
#   given+family pairs (P735/P734) of people with citizenship ZA, NG, GH, KE,
#   CI, TZ, SN, UG, ZW, ZM, ET, pulled from Wikidata 2026-09-11 by
#   datasets/pull_wikidata.py. Wikidata is CC0 1.0 (public-domain dedication);
#   see datasets/data/WIKIDATA_DATACARD.md. Adds the South African (Zulu,
#   Xhosa, Sotho, Tswana, Afrikaans) and West African family names the
#   13,342-name lexicon lacked: Khumalo, Mokoena, Botha, Plessis, Pieter ...
#
# Not a population register: Wikidata covers notable people. Words that are
# also common English words (Will, Rose, Hill, Park ...) are listed here as the
# surnames they are; arche.detect.names treats them as *weak* (they count only
# beside another name token or after a title or cue). Particles (van, der, de,
# du ...) are not names on their own and are ignored by the loader.
#
# Rebuild: the build script is not shipped; it takes the census CSV's first
# 3,000 rows (alphabetic names only) and the pairs file above, normalises with
# NFKD + combining-mark strip + lower(), and writes the sections in this order.
