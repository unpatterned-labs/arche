# Get started

Install arche, run three commands, then move to Python when you want the receipt in your own code.

- [Install](install.md): `pip install arche-core`, and the extras for the ledger, the document parsers, the models and the servers.
- [Five minutes](five-minutes.md): redact a sentence under its statute, compare two texts, and produce a shareable report, each one command.
- [From Python](python.md): the five verbs, one short example each, with what they print.
- [Docker and deploy](docker.md): the same commands from `ghcr.io/unpatterned-labs/arche-core`, and the compose file that puts an auth proxy in front.
