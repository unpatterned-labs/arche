# Far-duplicate recheck: the definition (fixed 2026-11-23, before review)

**Same** means one real facility, even if the HFR holds it twice.

For every pair in this pack, the GRID3 facility already has its own HFR record
(its twin, which shares its source id and is shown on the card), and the HFR
record being compared is a different one, 2 km or more away.

- **Same:** something besides the name shows it is the twin's facility, recorded
  a second time. For example, the same ward or address, the same phone or owner,
  or a map showing only one such facility in the area.
- **Different:** something shows two facilities, such as two buildings on the
  map or a different owner, or the names point to different places.
- **Can't tell:** only the name ties them. Common names (Blessed Hospital, God's
  Mercy Clinic) count as "only the name".
